# 거리잇기

실제 장소를 검색하고 두 지점 사이의 자동차 도로 거리를 확인하는 웹앱입니다.

## 실행 및 배포

- 빌드 과정, Redis, API 키, 환경변수 없이 Vercel에 배포할 수 있습니다.
- GitHub에 이 폴더를 저장소로 올린 뒤 Vercel에서 저장소를 Import하면 됩니다. Framework Preset은 `Other`로 두고 별도 빌드 명령이나 Output Directory를 지정하지 마세요.
- 로컬에서 확인하려면 Vercel CLI로 `vercel dev`를 실행하세요. API 함수가 포함되어 있어 정적 파일 서버만으로는 검색과 경로 계산이 동작하지 않습니다.

## 데이터 제공자 및 이용 안내

- 장소 검색: OpenStreetMap Nominatim
- 자동차 도로 경로와 거리: OSRM 공개 데모 서버
- 지도 링크: OpenStreetMap

Nominatim 공개 서비스는 사용 정책과 요청량 제한이 있으며, 이 앱은 브라우저 세션별로 검색 요청을 1초 간격으로 보내고 같은 페이지에서 같은 검색어를 다시 조회하지 않습니다. 이 간격은 모든 방문자를 합친 전역 제한은 아니므로, 다수 사용자의 요청량을 제한해야 하는 서비스에는 적합하지 않습니다. OSRM 공개 데모 서버도 별도 SLA가 없는 공용 서비스입니다. 따라서 이 설정은 개인적·소규모 사용을 위한 것이며, 대량 또는 상업적 트래픽이 예상되면 각 제공자의 정책을 확인하고 적합한 호스팅 서비스를 사용해야 합니다.
